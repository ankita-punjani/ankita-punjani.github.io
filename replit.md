# Ankita Punjani Portfolio

A static Jekyll portfolio for publication from the `main` branch and repository root on GitHub Pages.

## Source files

- `index.md`, `about.md`, `experience.md`, `contact.md`: page content and YAML front matter
- `_layouts/default.html`, `_includes/`: shared page structure and navigation
- `_data/navigation.yml`: the primary navigation links
- `assets/css/site.css`: responsive light-theme styles
- `_config.yml`: GitHub Pages site URL, empty base URL, SEO, and sitemap settings

Keep content factual to the supplied résumé and user-provided details. Do not fetch content from LinkedIn or publish the résumé's phone number.

## Content preferences

- Lead the home page with Ankita's gymnastics, skydiving, and contemporary dance facts, then introduce her work profile.
- Keep the public Work Profile to broad work areas and company names only. Leave job titles, dates, client/project details, and metrics for the résumé.
- Keep education simple: schools, degrees, and class years only. Do not include GPA, class rank, or awards.
- Include a direct LinkedIn link on the home page and Contact page.
